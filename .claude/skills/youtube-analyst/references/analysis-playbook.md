# Плейбук анализа

Оглавление: 1. Воронка · 2. Когорты по возрасту · 3. Дерево диагностики · 4. Проверка кластерной гипотезы · 5. Удержание · 6. Аудитория · 7. Названия и обложки · 8. Текст на превью

## 1. Воронка

Показы → CTR → просмотры → средний % просмотра → подписки / переход на следующее видео.

Для каждого видео определи слабое звено:
- **Мало показов при нормальных CTR и удержании** → проблема дистрибуции. Первая проверка: есть ли животное в заголовке? Это главный доказанный рычаг. Далее: кластер, возраст видео, сезонность, нет «мостов» от других видео.
- **Много показов, низкий CTR** → проблема названия/обложки или неверная аудитория показов.
- **Нормальный CTR, низкое удержание** → обещание не совпало с содержанием, слабое начало, провал в конкретном блоке.
- **Хорошее удержание, мало подписок** → нет призыва/причины подписаться, либо приходит случайная аудитория.

Опорный факт для этого канала: у слабых видео CTR и удержание стабильно здоровые (CTR 4–8.6%, удержание до 49%), узкое место — **показы**. YouTube решает не показывать обложку. Разница в показах между хитом и провалом — до 5 700 раз (3.76М vs 662). Разница в CTR — всего 2 раза.

## 2. Когорты по возрасту

Сравнивай видео на одинаковых днях жизни: день 1, 3, 7, 14, 28. Показатели: накопленные показы, просмотры, CTR, средний %, доля Browse/Suggested. Если у видео меньше данных, чем возраст сравниваемых, не выносить вердикт.

## 3. Дерево диагностики (слабые показы)

1. Сравнимо ли по возрасту? Если нет, вывод преждевременный.
2. **Есть ли животное в заголовке?** Все 3 хита канала содержат животное. Все провалы — нет. Это первый диагностический вопрос, до всего остального.
3. Сезонность: нет ли общей просадки по каналу в те же даты (посмотри по всем видео).
4. Источники трафика: чего не хватает, Browse или Suggested? Изменилась ли структура по сравнению с успешными видео? RELATED_VIDEO — единственный двигатель роста (у хитов > 50к рекомендаций, у провалов < 1.3к).
5. Кластер: есть ли у видео «соседи» по теме, откуда приходят рекомендации (см. раздел 4)? Но кластер работает только при соблюдении правила животного.
6. Название/обложка: не дублируют ли смысл прошлых видео, достаточно ли конкретно?
7. Только после этого гипотезы про «алгоритм наказал».

## 4. Проверка кластерной гипотезы

Гипотеза: радиоактивные темы (Чернобыль → Урал/Маяк → Семипалатинск и др.) поднимают друг друга в рекомендациях.
- Для каждого видео возьми детализацию `insightTrafficSourceDetail` для рекомендованного трафика: из каких видео приходят зрители.
- Построй матрицу «откуда → куда». Если рекомендации идут преимущественно внутри тематического кластера, гипотеза подтверждается.
- Сравни показы «нового» видео кластера и «не кластера» в одном возрасте.
- Итог формулируй с уровнем уверенности.

**Уточнение по данным канала:** кластер сам по себе не спасает без животного в заголовке. Рыжий лес (#7, Чернобыль) = 518 просмотров, хотя кластер «Чернобыль» — самый сильный. Фукусима (#10, «кабаны» в заголовке, ядерный кластер) = 1.2к — животное есть, но к сентябрю алгоритм потерял доверие к каналу после серии провалов. Кластер — усиливающий фактор, не самостоятельный.

## 5. Удержание

- Кривая по `elapsedVideoTimeRatio`. Отметь: провал в первые 30–60 с (хук), резкие спады (блоки-«убийцы»), пики пересмотров (то, что цепляет).
- Сопоставь провалы с блоками сценария и предложи правки для следующих видео. Для часовых фильмов важнее общая форма кривой, чем среднее значение.

## 6. Аудитория

Возраст, пол, страны, устройства, новые/вернувшиеся, подписчики/неподписчики.

Ключевые данные этого канала (30.09.2026):
- Ядро 45+: 66.4% (65+ = 27.5% — крупнейшая группа)
- Женщины: 37.1%, женщины 55+: 21.2%
- Украина #1 по просмотрам (716к), Россия #2 (567к)
- Аудитория смотрит YouTube как ТВ (длинные видео, фоновый просмотр)

Что делать с выводами: учитывать при выборе тем (женщины 55+ сильнее реагируют на природные/эмоциональные темы — поэтому «Затопленные миры» приоритетнее «военных баз»). Не подгоняй канал под демографию слепо, сначала проверь, что это устойчивый паттерн на нескольких видео.

## 7. Названия и обложки (заголовок видео)

**Главное правило: в заголовке ОБЯЗАНО быть конкретное животное.**

Не «природа», не «жизнь», не «существа» — конкретный вид: звери, лошади, рыбы, журавли, акулы, медведи, волки, лоси. Это единственное доказанное правило с разницей результатов в 1000+ раз.

Формула: **[ЖИВОТНОЕ + действие] + [место/контекст] + [парадокс/интрига]**

Примеры хитов:
- «Чернобыль захватили **звери**, которых не было 1000 лет» — 2.58М
- «Полигон, где живут **лошади**. Тайна Семипалатинска» — 177к

Примеры провалов:
- «**Оружие** конца света простояло 40 лет» — 2к (нет животного)
- «Самое **опасное место** в Чернобыле после реактора» — 518 (нет животного, даже Чернобыль не спас)

Дополнительные правила:
- Конкретика побеждает атмосферность: название, которое называет один физический объект, обычно сильнее размытого.
- Проверяй смысловые повторы с прошлыми названиями (алгоритм и зритель видят «то же самое»).
- Место/тему МОЖНО и нужно упоминать — это помогает YouTube подбирать аудиторию.
- Животное — в первой половине заголовка (это первое, что видит зритель в ленте).

## 8. Текст на превью (thumbnail text)

Текст на превью — вспомогательный элемент. Он не компенсирует плохой заголовок (52 БЕЛЫХ / МЕДВЕДЯ на превью = 1.3к, потому что заголовок был без животного).

Результаты текстов превью на канале:
- ЧЕРНОБЫЛЬ / ОЖИЛ → 2.58М (узнаваемый бренд)
- ВХОД / ЗАПРЕЩЕН → 394к (интрига/запрет)
- ВНУТРИ / ПРИПЯТИ → 17к (узнаваемое место)
- СМЕРТЬ / СПАСЛА → 2к (абстрактная метафора — провал)
- ДНО / МОРЯ → 2.5к (абстрактная метафора — провал)
- ЗАБЫТЫЙ / СЕВЕР → 1.7к (абстрактная метафора — провал)
- 52 БЕЛЫХ / МЕДВЕДЯ → 1.3к (животное на превью не спасло плохой заголовок)

Что работает: узнаваемое место/бренд (ЧЕРНОБЫЛЬ, ПРИПЯТЬ), интрига/запрет (ВХОД ЗАПРЕЩЕН).
Что НЕ работает: абстрактные метафоры без конкретики (СМЕРТЬ СПАСЛА, ДНО МОРЯ, ЗАБЫТЫЙ СЕВЕР).

Правила:
- Понятен за 1 секунду без контекста
- Конкретное слово лучше абстрактного
- Запрещены абстрактные метафоры — они стабильно проваливаются на этом канале
