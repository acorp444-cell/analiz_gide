# Стратегия и выбор тем

Оглавление: 1. Процесс · 2. Проверка безопасности · 3. Серийный тест · 4. Критерии оценки · 5. Формат выдачи

## 1. Процесс выбора темы

1. Собери кандидатов из: успешных кластеров канала, запросов в комментариях, Google Trends и подсказок, тем конкурентов, списка ожидающих проверки локаций.
2. **Проверь безопасность** (раздел 2) — стоп-критерий.
3. **Проверь наличие животного-героя** — обязательно для каждой темы. Если у локации нет документированного присутствия конкретных животных, тема не рекомендуется (или понижается в приоритете с пометкой «риск: нет животного»).
4. Оцени по критериям (раздел 4).
5. Отсей смысловые дубли с уже вышедшими видео.
6. Выдай ранжированный список (раздел 5).

## 2. Проверка безопасности локации (обязательна до всего остального)

Правило канала: никакой политики. Перед тем как предложить тему, через веб-поиск проверь актуальные данные:
- нет ли на территории действующей военной активности, полигона, закрытой зоны;
- нет ли связи с текущими конфликтами;
- нет ли рисков для съёмочного и сюжетного контента.

Ранее отсеянные: Тоцкий полигон, Капустин Яр (действующие военные объекты).
Городские заброшки / руферы — другая аудитория, другой формат, не предлагать.

Если проверка не пройдена или данных нет, помечай тему «не рекомендуется» и объясни почему.

## 3. Серийный тест кластеров (стратегия v3)

**Главный принцип:** новые направления тестируются сериями по 3 видео подряд, под защитой якорей из доказанного кластера (Чернобыль).

**Почему серия, а не одиночный эксперимент:** ни одно направление кроме ядерного не тестировалось серией из 3+ видео. Все провалы — одиночные вкрапления. Одно видео = случайность, три видео = паттерн.

**Критерий успеха серии:** 2 из 3 видео > 50к просмотров за 28 дней = кластер подтверждён.

**Порядок тестов (актуален на 30.09.2026):**
1. «Мировые заброшки» (ДМЗ Кореи → Атолл Бикини → Хэнфорд) — ДМЗ в работе.
2. «Затопленные миры» (Молога → Рыбинское → Байкал/БЦБК) — выбраны вместо военных баз из-за реальной демографии (женщины 55+ = 21% аудитории, сильнее реагируют на природные/эмоциональные темы).
3. Резерв: города-призраки мира, советские базы, экокатастрофы.

**Якоря Чернобыля:** сильные чернобыльские темы, которые вставляются между сериями тестов для поддержания алгоритмического доверия. Оставшиеся: ~2 (ночью/фотоловушки + Дуга).

**Отказ от пропорции 70/30:** старая рекомендация «70% проверенные, 30% эксперименты» нереалистична при темпе 4 видео/мес. Серийный тест (3 подряд одного кластера + якорь) эффективнее.

## 4. Критерии оценки темы

Обязательные (стоп-факторы):
1. **Безопасность локации** — проверка пройдена (раздел 2).
2. **Животное-герой** — у локации есть конкретное документированное животное, которое можно сделать героем заголовка. Не «природа вернулась» абстрактно, а конкретный вид: журавли, акулы, лоси, волки, медведи и т.д.

Балльные критерии:
- **Близость к работающему кластеру** — шанс на рекомендации от других видео канала.
- **Спрос** — тренды, поисковые подсказки, рост интереса.
- **Визуальная сила** — насколько заметно «природа вернулась» (главный приоритет канала).
- **Эмоциональный резонанс** — особенно для женщин 55+ (21% аудитории): история, судьбы, природа vs человек.
- **Новизна** — нет смыслового дубля с вышедшими видео.
- **Производственная реализуемость** — хватит ли материала для 45–70 мин фильма.
- **Украинская локация** — бонус: Украина = #1 по географии (716к просмотров).

## 5. Формат выдачи

Для каждой темы:
- Название темы и локация
- **Животное-герой:** конкретный вид для заголовка
- Почему сработает (данные, а не ощущения)
- Риски и статус проверки безопасности
- Предложение по названию (формула: [ЖИВОТНОЕ + действие] + [место] + [парадокс])
- Предложение по тексту на превью (конкретика, не метафора)
- Как проверить успех (метрика и срок)
- Место в серийном тесте (если это часть серии)
